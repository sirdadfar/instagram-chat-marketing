# Instagram Chat Marketing

پنل حرفه‌ای مدیریت و اتوماسیون اینستاگرام با Laravel 12 و PHP 8.3 — چندکاربره (Multi-tenant).

## امکانات

- اتوماسیون کامنت، Story Reply و پیام‌های Instagram
- Follow Gate و مرحله Verify
- Button Builder و Media Picker
- Inbox و مدیریت گفتگو
- مدیریت محتوا و نظرات
- Webhook و جلوگیری از پردازش تکراری
- Database Queue بدون Redis
- داشبورد فارسی RTL و موبایل‌محور
- CI/CD خودکار برای Production

## معماری چندکاربره

- هر کاربر با ایمیل و رمز خود ثبت‌نام می‌کند (ثبت‌نام آزاد + Rate-limit ضد سوءاستفاده)
- هر کاربر فقط پیج‌های خودش را می‌بیند و مدیریت می‌کند؛ مالکیت پیج، مرز تفکیک همه داده‌هاست: اتوماسیون‌ها، اینباکس، مخاطبین، نظرات، محتوا، قالب پیام و کتابخانه رسانه
- هر کاربر کلید سرویس (Zernio API Key) اختصاصی خودش را از صفحه «تنظیمات» وارد می‌کند؛ مقدار رمزنگاری‌شده در دیتابیس ذخیره می‌شود و اولویت آن از `.env` بیشتر است
- ادمین در منوی «مدیریت کاربران» نظارت کامل دارد: فعال/غیرفعال کردن کاربر، ریست رمز، تبدیل به ادمین، حذف کاربر و واگذاری مالکیت پیج‌ها؛ ادمین به همه داده‌ها دسترسی دارد
- پیج‌های موجود در نصب‌های قدیمی پس از استقرار به‌صورت خودکار به کاربر ادمین واگذار می‌شوند (`php artisan panel:adopt-legacy` — خودکار در CI/CD اجرا می‌شود)

## متغیرهای محیطی مهم

| متغیر | نقش |
|---|---|
| `PANEL_ADMIN_EMAIL` | ایمیل ادمین اولیه هنگام Bootstrap (اختیاری) |
| `PANEL_ADMIN_USERNAME` | نام کاربری ادمین اولیه (پیش‌فرض: بخش محلی ایمیل یا `admin`) |
| `PANEL_ADMIN_PASSWORD` | رمز اولیه ادمین (اختیاری؛ اگر خالی باشد رمز تصادفی ساخته و یک‌بار در لاگ استقرار نمایش داده می‌شود) |
| `ZERNIO_API_KEY` | کلید سراسری پیش‌فرض سرور (fallback؛ هر کاربر کلید خودش را در پنل وارد می‌کند) |
| `ZERNIO_WEBHOOK_SECRET` | رمز امضای وبهوک (سراسری؛ فقط ادمین از پنل می‌تواند تغییر دهد) |
