# Instagram Chat Marketing

پنل حرفه‌ای مدیریت و اتوماسیون اینستاگرام با Laravel 12 و PHP 8.3.

## امکانات

- اتوماسیون کامنت، Story Reply و پیام‌های Instagram
- Follow Gate و مرحله Verify
- Button Builder و Media Picker
- Inbox و مدیریت گفتگو
- مدیریت محتوا و نظرات
- Webhook و جلوگیری از پردازش تکراری
- Database Queue بدون Redis
- داشبورد فارسی RTL و موبایل‌محور
- CI/CD خودکار برای Production

راهنمای استقرار: docs/CI_CD.md و docs/PRODUCTION.md

## تنظیم کلیدها از پنل

علاوه بر `.env`، کلید دسترسی سرویس، رمز امضای وب‌هوک و رمز ورود پنل را می‌توان از صفحه «تنظیمات» وارد کرد. مقادیر واردشده رمزنگاری‌شده در پایگاه‌داده ذخیره می‌شوند و اولویت آن‌ها از `.env` بیشتر است، بنابراین هر کاربری بدون دسترسی به سرور می‌تواند پنل را راه‌اندازی کند.
