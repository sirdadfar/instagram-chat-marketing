# ارسال متن، رسانه و ویس

پنل برای پیام‌های Instagram از قابلیت Inbox زرنيو استفاده می‌کند.

- متن: تا ۱۰٬۰۰۰ کاراکتر در composer داخلی پنل.
- تصویر/ویدیو/صوت: ابتدا از مسیر `POST /v1/media/upload-direct` در Zernio بارگذاری می‌شود و URL عمومی برگشتی با `attachmentUrl` در پیام ارسال می‌شود.
- ویس: ضبط مرورگر پس از پایان به WAV تبدیل و سپس بارگذاری می‌شود. محدودیت ضبط رابط کاربری ۶۰ ثانیه است.
- حداکثر حجم فایل برای آپلود مستقیم پنل ۲۵ مگابایت در نظر گرفته شده است.

## محدودیت Instagram

Zernio برای Inbox اینستاگرام ارسال متن و attachmentهای image/video/audio را پشتیبانی می‌کند. فرمت‌های صوتی قابل قبول Instagram شامل AAC، M4A، WAV و MP4 است؛ MP3 و OGG/Opus برای Instagram مجاز نیستند.

در `private-reply` کامنت، API فعلی Instagram فقط متن را به‌همراه quick reply یا دکمه پشتیبانی می‌کند. به همین دلیل گزینه رسانه در این نوع پاسخ در رابط کاربری غیرفعال می‌شود و برای ارسال رسانه باید از پاسخ دایرکت استفاده شود.
