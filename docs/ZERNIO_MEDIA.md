# دریافت رسانه‌های اینستاگرام

پنل برای انتخاب رسانه به ترتیب زیر عمل می‌کند:

1. `GET /v1/accounts/{accountId}/posts` برای دریافت رسانه‌های اخیر حساب اینستاگرام.
2. اگر مسیر مستقیم به‌دلیل endpoint/account mismatch یا خطای provider شکست بخورد، `POST /v1/posts/sync-external` با `accountId` برای همگام‌سازی رسانه‌های خارجی و دریافت `posts[]` امتحان می‌شود.
3. هنگام خطا، وضعیت حساب با `GET /v1/accounts/{accountId}/health` بررسی می‌شود تا خطاهایی مانند نیاز به اتصال مجدد یا نبود مجوز خواندن رسانه مشخص شوند.

شناسه‌ای که در پنل به کاربر نمایش داده نمی‌شود، فقط در پشت‌صحنه برای ساخت automation به‌عنوان `target_id` نگهداری می‌شود.
